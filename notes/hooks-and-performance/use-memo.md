# useMemo

> دسته: React Hooks & Performance

از این هوک زمانی استفاده می‌شه که بخوایم نتیجه‌ی یک محاسبه رو بین رندرها کش کنیم. وقتی کامپوننت `rerender` می‌شه، `useMemo` فقط در صورتی محاسبه رو دوباره انجام می‌ده که یکی از مقادیر داخل آرایه‌ی `dependency` تغییر کرده باشه؛ در غیر این صورت، همون مقدار کش‌شده‌ی قبلی رو `return` می‌کنه.

```jsx
  useMemo(() => isEven(firstNumber), [firstNumber])
```

مثلا یک `state` داریم به اسم `firstNumber` که یک عدد را داخلش ذخیره میکنیم و یک تابع داریم که بررسی میکنه آیا این عدد زوج هست یا نه و این تابع برای نمایش داخل `component` خروجی رشته ای دارد برای همین داخل `jsx` قرار دارد

پس زمانی که `state` دیگری بجز `firstNumber` تغییر کند کامپوننت `rerender` میشود و این تابع `isEven` هم باز اجرا میشود در صورتی که نیاز به اجرا شدنش نیست چون مقدار خروجی اش قرار نیست متفاوت باشه در این جا از `hook useMemo` استفاده میکنیم مانند دستور بالا که یعنی اگر مقدار `state firstNumber` تغییری داشت این تابع اجرا شود در غیر این صورت همان مقدار قبلی تابع در `render` قبلی `return` میشود


**نکته:**
خود `useMemo` یه `overhead` داره (نگه‌داشتن `dependency` + مقایسه). برای محاسبات ساده، استفاده ازش می‌تونه بدتر از استفاده نکردنش باشه. فقط برای محاسبات سنگین یا مقادیری که `reference`‌ شون مهمه (مثل آرایه/آبجکت پاس‌داده‌شده به کامپوننت `memo` شده) ارزش داره.
<br/>
<br/>

**تفاوت بین `useMemo` و `useCallback`** <br/>
`useMemo` → یه مقدار رو کش می‌کنه (نتیجه‌ی اجرای تابع). <br/>
`useCallback` → خود تابع رو کش می‌کنه (ثابت `reference`).

# React & JavaScript Learning Notes

یادداشت‌های شخصی من از مسیر یادگیری React و جاوااسکریپت — نکاتی که خودم لازم داشتم یادشون بگیرم، یا جاهایی که توی مستندات رسمی راحت پیدا نمی‌شدن، به همراه چندتا اشتباه رایج.

هر موضوع یک فایل جداگانه است تا بتوانم آن‌ها را به‌مرور و روز به روز داخل گیت قرار دهم.
